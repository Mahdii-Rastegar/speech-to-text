آوانویس (Avanevis)
تبدیل گفتار به متن، فارسی و انگلیسی

اجرا
-----
روی Avanevis.exe دوبار کلیک کنید. نصب لازم ندارد. کل این پوشه را می‌توانید
هر جا کپی کنید (درایو دیگر، فلش، کامپیوتر دیگر) و از همان‌جا اجرا کنید.

بار اول
-------
۱. موتور محلی برای کار کردن یک فایل مدل می‌خواهد. در برنامه به
   «تنظیمات» ← «مدل‌های موتور محلی» بروید و مدل پیشنهادی را دانلود کنید
   (حدود ۵۵۰ مگابایت، فقط یک بار). بعد از آن موتور محلی بدون اینترنت کار می‌کند.
۲. اگر به‌جای آن موتور ابری (OpenRouter یا Google Gemini) می‌خواهید، کلید خودتان
   را در «تنظیمات» ← «کلید API» وارد کنید. مدل لازم نیست، ولی اینترنت لازم است.

چه چیزی کجا نگه داشته می‌شود
-----------------------------
data\      تاریخچه‌ی جلسه‌ها و تنظیمات شما. برنامه خودش آن را می‌سازد.
models\    فایل‌های مدل که دانلود کرده‌اید.
engine\    موتور محلی (whisper.cpp). به آن دست نزنید.

کلیدهای API داخل این پوشه نیستند: در Credential Manager ویندوزِ همان کامپیوتر
می‌مانند. پس با کپی کردن پوشه، کلیدها همراهش نمی‌روند و روی کامپیوتر تازه باید
دوباره وارد شوند.

صدا هیچ‌وقت ذخیره نمی‌شود؛ فقط متن جلسه‌ها.

اگر این پوشه را به کس دیگری می‌دهید
------------------------------------
پوشه‌ی data را همراهش نفرستید: تاریخچه و تنظیمات شخصی شما داخل آن است.
پوشه‌ی models را می‌توانید بفرستید تا گیرنده مجبور به دانلود دوباره نباشد.

سرعت و کارت گرافیک
-------------------
موتور محلی روی هر کامپیوتری کار می‌کند، ولی بدون کارت گرافیک NVIDIA کند است و
متن با تأخیر می‌آید. اگر کارت NVIDIA دارید، فایل‌های «بسته‌ی GPU» را داخل پوشه‌ی
engine کپی کنید تا موتور چند برابر سریع‌تر شود. بدون کارت NVIDIA، برای متن زنده
موتور ابری مناسب‌تر است.

نیازمندی‌ها
-----------
ویندوز ۱۰ یا ۱۱، ۶۴ بیتی. برنامه از WebView2 استفاده می‌کند که روی ویندوز ۱۱ و
ویندوز ۱۰ِ به‌روز از قبل نصب است. اگر برنامه باز نشد، «WebView2 Runtime» را از
سایت مایکروسافت نصب کنید.

پوشه باید جایی باشد که برنامه اجازه‌ی نوشتن دارد (مثلاً Documents یا یک درایو
دیگر، نه Program Files).


Avanevis: offline-first speech-to-text for Persian and English.
Run Avanevis.exe; nothing is installed. Download a model once under
Settings, or enter your own OpenRouter / Google AI Studio key to use a cloud
engine. The data folder holds your history and settings: leave it out when
you pass this folder on. API keys live in the Windows Credential Manager of
the computer they were entered on, not in this folder.
Third-party notices are in the licenses folder.
